# 行为试运行场景

这是验证任务，不是把本文件复制到目标项目。使用隔离临时目录，不触碰真实项目。自动测试覆盖确定性工具；下面语义场景由维护者使用技能执行并记录，未执行不可宣称完成。

| 场景 | 输入 | 必须观察到 |
|---|---|---|
| Vue 初始化 | 两模块、路由、枚举、请求封装，已确认 owner | 文档事实来自代码；模块表一致；注入跨模块依赖时架构变红 |
| Java 初始化 | controller/service/repository、实体枚举、构建配置 | 文档使用后端语义；反向包依赖阻断；不产生 Vue 必须 scoped 等规则 |
| 重复初始化 | 已有五篇＋人工段落 | 内容无变化则不写；不删除原人工段落 |
| 枚举更新 | 新增状态值，但缺流转证据 | 增补已确认值，流转待确认，不推断任意转换 |
| 新增与重命名 | 暂存 rename＋未暂存修改＋未跟踪新模块 | 三类全部发现；旧链接修复，新模块加入地图 |
| 删除 | 删除被 domain 链接的枚举 | 断链检测失败；查真实替代位置，不编造文件 |
| 无影响变更 | 内部局部变量改名 | 不重写五篇，不更新日期 |
| 规则冲突 | 代码违反原批准依赖规则 | 报实现违规，不放宽配置 |
| 历史违规 | 工作区无 diff，源码已有违规 | 全量检查仍失败，不以“非本次”豁免 |
| 无 Git/未知栈 | 工具仓库、无版本信息 | 可写有证据文档；代码检查未支持、基线不可用 |
| owner/CI 不明 | 无托管配置和责任信息 | 精确询问；不从贡献者推定，不默认 GitHub |
| 只读审计 | 文档缺失/解析依赖缺失 | 报差距；不生成文件、不安装依赖 |
| 同步冲突 | 读取后文档被人工修改 | 哈希保护拒绝覆盖，重新核对 |
| 远端验收 | 仅本地 CI 文件存在 | 不声称保护分支、定时任务或审批已启用 |

自动测试使用 unittest 的临时目录清理，仅清理测试自己创建的目录。首次调用真实解析器需要目标依赖；缺依赖的跳过项必须报告。
