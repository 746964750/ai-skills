# 实际验收与证据

静态通过、构建通过、视觉通过、真实业务通过分别记录。不能用一个替代另一个，也不要求为了纯样式验收执行真实删除或保存。

## 静态与业务边界

1. manifest 资产完整，主题只引入一次；作用域覆盖管理端和明确的传送层，排除页面未污染。
2. 直接使用原生组件；控件 default、工具栏 small、选择/序号列固定 40 且双向居中；无按钮级 iconfont。
3. 无效动态按钮过滤、有效名称与原对象保持；数字占位图标不留空按钮，tooltip 图标按钮有辅助名称。
4. 受控分页配 update 事件，初始 total=null 可渲染；查询和分页每次只触发一次请求。不要清空已知 total 导致加载时页码变动。
5. 字段初始化/联动/异步校验/上传/排序/选择、权限与值类型仍符合原业务。样式修改不顺带修复不相关业务。
6. 运行项目现有检查；旧失败列为存量，规则不降级。没有本地依赖时说明未运行，不临时安装另一套 UI 库。

## 视口矩阵

| 视口 | 必查 |
| --- | --- |
| 1920×1080 | 菜单、页签、字段与操作顺序，足够宽时查询条件仍左排 |
| 1440×900 | 普通表单、宽表横向滚动、分页、弹窗页脚 |
| 1280×720 | 有限高度下的按钮和弹窗内容，不能固定高度截掉下半部 |
| 768px 宽 | 侧栏收缩、查询换行、按钮换行、弹窗最大宽、分页可达 |
| 480px 宽（左排问题时） | 320px 设计列宽自然换行，字段没有页面水平溢出 |

保留并恢复临时视口、侧栏和测试勾选。宽表内部横向溢出允许，整个页面横向溢出不允许；不要把主滚动区内的下面几行误判为数据丢失。

## DOM 测量

浏览器工具允许只读 DOM 时，将 `scripts/browser_layout_probe.js` 的表达式用于 evaluate；不把 Node/Python 浏览器自动化强加给工具不支持的环境。结果只含标签、序号、几何与样式，不读凭据、表格业务字段或内部应用状态。

- 查询内容上下空隙对称且缩小；来源视口 1536px 的旧内容区约 72 CSS px、修正后约 43 CSS px，只供对照，不能在别的缩放下硬断言同高。
- 相邻条件列从左连续排列，间隔按缩放后的 16px 设计值，空白留在整组右侧。
- 选择列原生 width=40，表头与各行 checkbox 的中心偏差应在 1 CSS px 内；旧来源偏差约 0.25px。
- 序号列各行和表头 width=40，text-align=center，nowrap，无内容横向裁切；同时核对 1、10、20。有实际双/三位序号时再检查，不修改生产序号算法制造数据。
- 普通字段高度一致；实际数值由项目缩放决定，不能用 inline style 逐字段凑高度。
- 弹窗/抽屉取消和保存区域可见或可滚动到达；内容滚动不能把 footer 永久藏在 overflow:hidden 之后。

探针失败或工具不支持时改用原生 DOM 检查/截图，明确未覆盖项，不伪造探针结果。

## 交互与真实数据

检查查询/重置、分页、单行选择/全选/清空、排序、打开详情、取消返回、长文本语言、加载/禁用和空态。编辑提交/删除/权限修改仅在用户明确授权的业务验证范围内执行。后端返回失败时保留错误事实，不用演示 adapter 替换生产请求再称真实通过。

Token 失效时请用户正常重新登录；登录后再回到原场景。正常入口与登录守卫不得为样式任务绕过。没有真实抽屉路由时写“无真实实例”，只把演示抽屉记录为视觉样例通过。

## 交付格式

简述改了什么、实际运行的命令和结果、浏览器视口/场景及未覆盖项。留存至少一张对应改动的实际效果图和结构化测量；没有浏览器时明确视觉待验收。模拟预览必须显式标注演示数据。截图不要求包含真实账号、人员、物料或接口信息；可用隔离演示样例分享风格。

分享新版本时：同步契约与资产 → 静态 checker 和脚本回归 → 编译模板 → 浏览器验证演示与实际页面 → 更新 manifest → 验证打包内容。不要仅更新 manifest 来允许未经确认的视觉漂移。
