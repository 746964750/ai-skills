# 一致性验收

## 静态检查

在目标工程根运行 SKILL.md 的命令。`check_style.py` 不依赖 Node 或 Vue parser；它是有限的 SFC/HTML 结构检查器，不替代 Vue 编译、运行时和截图。它不能穷尽 SCSS 混入、动态 style/class、第三方主题注入等覆盖路径。

- `--assets-only`：核对 manifest 锁定文件、相对链接、模板结构。
- `--project` + `--page`：核对目标主题/骨架与标准资产一致，扫描 CSS/Vue 样式块中的固定样式覆盖，检查所选页面结构。主题与骨架路径可用 `--theme`/`--shell` 改映射。
- 可重复 `--page`，只传本次页面；不要把尚未迁移的历史死文件当成本次实现。
- 退出 0 = 检查范围内通过；退出 1 = 可定位的问题；退出 2 = 参数/文件/解析等无法形成结论。未通过时保留证据，不改工具/manifest 掩盖漂移。

维护技能时执行 `python <skill-dir>/scripts/test_check_style.py`；这些回归覆盖正常资产、换行差异、主题/骨架漂移、旧控件、覆盖样式、缺失文件和分发包篡改。目标 Vue 项目已安装 `@vue/compiler-sfc` 时还可运行 `node <skill-dir>/scripts/verify_templates.mjs <project-root>`，编译标准骨架和四个模板；不因此改动项目依赖。

受限环境不能写系统临时目录时，将进程环境变量 `WMS_PDA_STYLE_TEST_TMP` 指向一个已存在的可写临时目录，再运行回归；测试只在其中创建并清理自己新建的随机子目录。

## 浏览器与截图

| 视口 | 必须覆盖 |
| --- | --- |
| 320×640 | 英文长标签/长按钮、查询输入、分页、弹窗，无页面横向溢出 |
| 360×740 | 中文扫码表单、长名称与连续 40 字符条码、明细空态与多条结果 |
| 640×360 | 横屏内容可以滚动，操作区完整可达，最后一行不被按钮遮挡 |
| 桌面如 1280×800 | 内容居中且不超过 760px，登录卡不超过 400px，菜单三列 |

将 `scripts/browser_layout_probe.js` 的整个函数表达式交给可用浏览器的 read-only evaluate，在页面稳定后调用；它只读 DOM，不注入样式、不改变状态。保存结果 JSON 和截图。没有此能力时用真实浏览器/开发者工具核对同样项目，并注明手工范围。

探针在小数尺寸比较时允许 1px 舍入误差，检查可见控件高度、标题/主题实际颜色、业务页主体与 footer 的关系；表格内部滚动允许。它只检查当前页面/状态/视口，不能推断其它状态通过。空权限/失败等状态必须单独实际触发或通过标记清晰的预览夹具验证。

以 `assets/preview/operation-360.png` 对照：标题栏高度/底边、卡片/表单边距、字体层次、输入高度、只读字段、明细两列、底部按钮。换行位置可因平台字体不同有少量差异，不允许改变设计 token 来“调成看起来相似”。登录/菜单使用对应标准 SCSS 的数值验收，不从业务截图猜布局。

## 交互与行为

1. 实际扫码输入的 ref 存在，首次进入及重进的焦点仍符合原流程；清空按钮后可继续扫码。样式重构不改变 input/Enter 触发方式。
2. back 与底部返回调用原处理函数。确认按钮 loading/disabled 正确，加载期间不会重复提交。
3. 切换出库模式时字段与确认操作同时切换，不出现两套动作或保留错误模式参数。
4. 表格向后翻页确实请求目标页，查询条件不丢失；请求加载时不因 total=0 自动跳回 1。确认真实 Element Plus 组件无 prop 校验警告。
5. 弹窗窄屏可达、确认/取消文字完整，条码数据未变；专用条码渲染单独检查，不用示意图替代真实编码。
6. 固定文案随语言更新，业务 code/value 与客户内容不变；只读/禁用、loading、空、失败与重试状态可辨认。

按改动风险使用项目已有测试入口；为骨架/插槽迁移测试焦点与事件、分页和模式切换等实际行为。不要仅做“文件包含某个类名”的镜像测试来证明交互正确。

## 报告格式

给出：采用的技能版本/源提交、改动页面、静态检查结果、构建/交互结果、视口和状态截图、批准的偏离与未验证项。无环境时不得声称真实设备、后端写入、软键盘或网络异常恢复已验收。

无需把某台电脑的 Node 路径、端口或临时内存参数写入页面。使用目标项目的 package.json 与版本守卫；资源不足时可临时限制并行度，报告准确命令，不借此修改业务配置。
