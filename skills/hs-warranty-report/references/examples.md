# 质保报工句式示例

## 单次报障

**输入线索**：计划模块统计失败；脚本版本旧；升到 V2.3；验证 OK

**输出**：

```markdown
**项目名称**：XX 集团 ERP 系统建设项目

**具体工作内容**：
处理客户报障：计划模块统计报错，排查为脚本版本不一致，升级至 V2.3 后验证通过。
```

## 缺陷修复 + 文档

**输入线索**：入库单打印空白；模板字段映射缺；补映射；复打通过；提交配置库

**输出**：

```markdown
**项目名称**：【待补：项目标准名称】

**具体工作内容**：
排查入库单打印空白：定位打印机模板字段映射缺失，补齐映射并现场复打通过；已将修订模板提交配置库。
```

## 近一周合并（模式 B）

**输入线索**（7 日内多 session）：① 审批流回调超时改网关；② 报表导出编码乱码改 UTF-8；③ 编写操作说明

**输出**：

```markdown
**项目名称**：XX 集团 ERP 系统建设项目

**具体工作内容**：
处理采购审批流超时：回调改走内网网关后压测通过；修复报表导出乱码为 UTF-8 并复测导出；交付操作说明一页供现场使用。
```

## 用户声明项目名后应写入记忆

用户：「当前项目是 华润医药 MES 升级项目」

Agent：报工使用该名称，并写入 `.cursor/rules/hs-warranty-project.mdc`，下次直接读取。
