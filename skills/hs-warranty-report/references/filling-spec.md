# 售后报工填写要求（权威原文）

每条售后报工需完整填写以下两项核心信息，不得缺项、漏项：

1. **项目名称**：填写原实施项目的完整标准名称，确保与项目备案信息一致，便于精准追溯售后工时与对应项目的关联关系。

   示例：XX 集团 ERP 系统建设项目

2. **具体工作内容**：详细描述本次售后处理的完整事项，需包含**问题现象、处理过程、输出物**，严禁使用 “维护”“支持” 等笼统模糊表述。

   示例：处理客户报障：计划模块统计报错，排查为脚本版本不一致，升级至 V2.3 后验证通过。
