# 可选工作流

[返回仓库导航](../../README.md)

根据任务选择阶段，不要求串联全部技能。先确认技能已安装，按目标仓库规则执行。

- [PRD 撰写](PRD%20撰写.md)：从需求探索、PRD 撰写、设计交付或需求评审中选择当前阶段；已有 PRD 时可直接进入评审，不重复探索。
- [UI 原型设计](UI%20原型设计.md)：区分新原型、设计稿还原和已有界面优化；WMS 项目优先复用对应终端样式，无需先执行整套设计系统流程。
- [代码重构](代码重构.md)：仓库摸底、架构评估和代码重构是不同目标；先明确行为约束与范围，再选择必要的分析或实施步骤。
- [Bug 排查](Bug%20排查.md)：优先用一个主诊断流程建立复现和根因证据；有日志时配合日志分析，不重复串联多套调试协议。NEXUS 属于外部服务，需单独核验数据和费用条件。
- [自动化测试](自动化测试.md)：按测试计划、用例交付、TDD、接口或 E2E 目标选择技能；不要求每次同时生成计划、Excel 和所有类型测试。
