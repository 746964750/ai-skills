Agents 一句话（整行复制发给 Agent）

  • 先读 SKILL.md：按工作流与 references 执行，勿跳过质量门禁。
  • Harness 优先：ai-coder / code-review / diagnosing-bugs 遵循目标仓库 AGENTS.md。
  • 需求抽取先声明主体；报工只基于证据，勿编造。
  • 按领域选 agents：产品文档 → PRD；界面 → UI；质量 → Bug/测试；结构 → 重构。
